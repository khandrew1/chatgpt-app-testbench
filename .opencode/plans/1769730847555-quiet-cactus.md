# CSP Testing Widget Implementation Plan

## User Requirements (Clarified)
- **Domains**: Use example domains (https://httpbin.org for connect, https://via.placeholder.com for resources)
- **Testing**: Perform real requests to verify CSP allows/blocks them
- **UI**: Simple display widget showing test results

## Implementation

Create a CSP testing widget at `web/widgets/csp-test.tsx` that:
1. Displays the configured CSP domains
2. Performs actual fetch() requests to test connect_domains
3. Attempts to load images to test resource_domains
4. Shows pass/fail status for each test
5. Handles errors gracefully (CSP blocks will throw errors)

Update widget registration in `server/widgets/config.ts` with CSP configuration including connect_domains and resource_domains.

Add build entry to `web/package.json` for the new widget.

## Verification

1. Run `npm run build` in web/ directory
2. Run `npm run dev` to test locally
3. Verify widget loads and shows CSP test results
4. Confirm CSP domains are properly passed in the widget metadata

## Files to Modify
- `web/widgets/csp-test.tsx` (create)
- `server/widgets/config.ts` (add widget registration)
- `web/package.json` (add build entry)
